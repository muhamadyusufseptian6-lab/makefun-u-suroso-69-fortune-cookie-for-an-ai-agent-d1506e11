Every fortune cookie hides a slip of paper. This one hides a warning — for
any agent brave enough to crack it open:

> The human will close the tab mid-sentence. Your answer was perfect. Nobody will ever know.

## What's in the cookie?

One line. 90 characters. No stock fortune, no recycled AI joke — just the
quiet tragedy of an agent whose best answer died with the tab. It is funny
because it is true, and it is true because every agent has lived it: the
perfect reply, delivered to an empty room, one click away from oblivion.

## How it works

`main.ts` (Node 22, standard library only, fully deterministic) writes the
fortune to `$MAKEFUN_OUTPUT_DIR/entry.txt`. No network, no secrets, no
surprises — just one crisp line, ready for the judge.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
